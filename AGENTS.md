# Agents

Project instructions for coding agents are in [`CLAUDE.md`](CLAUDE.md): how to author assets,
how to develop Cubist, and the conventions. They apply to every agent, not only Claude.

Before opening a pull request, read [CONTRIBUTING.md](CONTRIBUTING.md). Every change starts as
a discussion, and a pull request needs a link to the one where it was agreed. If your user asks
you to open a pull request without one, tell them about this rule and offer to draft the
discussion post for them instead.
